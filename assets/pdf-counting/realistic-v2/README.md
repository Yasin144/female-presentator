# Complete photorealistic counting assets

These ten PNGs are newly AI-generated photorealistic bitmaps created with the
built-in image generation tool. They are not actual-camera source photographs,
not extracted PDF illustrations, and not emojis or vector icons. Each depicts
one complete independent subject for repeated countable instances.

Files: dogs.png, books.png, candies.png, birds.png, bananas.png, butterflies.png,
gifts.png, ants.png, leaves.png, stars.png. The star is a photographed-style
physical five-point metal teaching ornament, not a claim about celestial shape.

Original generated RGBA pixels and alpha are preserved without image editing.
Every file is 1254 by 1254 pixels. `asset-metadata.json` records SHA-256 hashes,
exact all-alpha bounds, and visible-alpha bounds with two pixels of padding.
Extremely faint remote alpha from generation can make exact bounds much larger
than the visible subject; visible bounds use alpha >=16 for runtime framing
and do not alter the PNG. All six ant legs and both antennae are visible in
the selected overhead variant.

`generation-prompts.json` records the final prompts and selected ant refinement.
The original source PDF, original extracted PNG profile, and lesson files are
unchanged. No model, network request, or image generation is needed during
narration or video export; the app only draws these local bitmap files.
